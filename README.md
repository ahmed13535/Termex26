# 🌍 عصر الأمم – Struggle of Nations

> بوت تيليجرام استراتيجي متعدد اللاعبين يمكّنك من بناء دولتك، وإدارة اقتصادها، وخوض الحروب، وبناء الأحلاف — كل ذلك داخل تيليجرام.

---

## 📌 نظرة عامة

**عصر الأمم** هو بوت لعبة استراتيجية بالزمن الحقيقي تتنافس فيه الدول على الهيمنة. يتحكم كل لاعب في دولة أوروبية وعليه إدارة:

- 💰 **الاقتصاد** — الذهب، الغذاء، الطاقة، المباني
- ⚔️ **الجيش** — التجنيد، الهجوم، الدفاع، الاحتلال
- 🤝 **الدبلوماسية** — الأحلاف، معاهدات السلام، الحماية
- 🕵️ **المخابرات** — التجسس، التخريب، الاغتيال
- 📈 **البورصة** — شراء وبيع الأسهم
- ☢️ **المشاريع الضخمة** — تطوير أسلحة نووية وبيولوجية
- 🗺️ **الخريطة** — عرض حي لمواقع الدول والأراضي المحتلة

---

## ⚙️ التثبيت والتشغيل

### المتطلبات
- Python 3.11+
- SQLite 3

### الخطوات

```bash
# 1. استنسخ المشروع
git clone https://github.com/yourname/era-of-nations-bot.git
cd era-of-nations-bot

# 2. أنشئ بيئة افتراضية (موصى به)
python -m venv venv
source venv/bin/activate   # Linux/Mac
# أو: venv\Scripts\activate  # Windows

# 3. ثبّت المكتبات
pip install -r requirements.txt

# 4. اضبط متغيرات البيئة
cp .env.example .env
# عدّل .env وأضف توكن البوت ومعرفات الأدمن

# 5. شغّل البوت
python main.py
```

### إعداد `.env`
```env
BOT_TOKEN=your_bot_token_here
ADMIN_IDS=123456789,987654321
DB_PATH=civ_bot.db
FLAGS_CACHE_DIR=assets/flags_cache
```

## 🔔 نظام الإشعارات

البوت يرسل إشعارات فورية عند:
- إعلان حرب عليك
- تعرضك لهجوم (مع تفاصيل الخسائر)
- وقوع كارثة طبيعية
- تلقي دعوة حلف (مع أزرار قبول/رفض)
- تلقي عرض سلام أو حماية
- اكتمال مشروع نووي/بيولوجي
- تغيّر حاد في أسعار البورصة
- إغلاق مضيق يؤثر عليك

كل مستخدم يمكنه تخصيص إشعاراته عبر: `إعدادات الإشعارات`
